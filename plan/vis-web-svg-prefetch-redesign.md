# 重构 SVG 预加载与调试状态

## 总结

- 将 SW 预加载的 SVG 从 Cache Storage 改为共享 IndexedDB 原始 SVG 缓存，页面使用时再解码，避免后台 PNG 栅格化和重复网络读取。
- SW 始终只预加载前端计算出的最新起报时次；页面相邻预报时效预加载继续保留。
- 前台发生 `/data/` 请求时立即中断后台预加载，连续空闲 2 秒后再恢复。
- 在左侧控制栏展示 SW 预加载状态与图片计数，在全局设置中增加默认开启的总开关。

## 实现变更

### 缓存层

- 将 `WeatherSystemVisualization` IndexedDB 升级到 v2，新增原始 SVG store，记录 URL、Blob、内容类型、起报时次、缓存时间和 72 小时过期时间。
- 保留最多 600 张已解码图片的内存 LRU；页面从 IndexedDB 读取原始 SVG 后按当前倍率解码。
- 删除旧的持久化 PNG store 和 `weather-tiles-v1` SVG 缓存；它们均为可再生成缓存，不迁移旧数据。
- Manifest 与 SW 选项继续保留网络优先和离线回退；过期 SVG 在激活及预加载前清理。
- 页面主动加载和相邻时效预加载也写入同一个原始 SVG store；相邻预加载只缓存源文件，不提前解码或 Canvas 转 PNG。

### SW 调度

- 页面启动、`controllerchange`、重新可见和“保存并应用”只下发 `calLatestBaseTime()` 对应的一个起报时次。
- Manifest 收集同时支持单文件 `record.path` 和按 z 分片的 `record.tiles[z]`，应用现有 z、要素和气压层过滤，跳过失败项并去重。
- 后台并发降为 2；新起报到达时中断旧任务，旧缓存保留至过期。
- 持久化任务元数据，包括起报时次、选项指纹、Manifest 版本、总数、已就绪数、下载数和失败数；相同任务已完成时直接复用结果，避免页面反复可见时重新遍历和下载。
- 任一受控页面发起同源 `/data/` 请求时，将 SW 状态切为“前台请求暂停”，Abort 正在进行的预加载请求；最后一次前台请求后连续空闲 2 秒才继续。
- 维持 60% 存储软上限，达到上限后以独立状态停止，而不是报告为完成。
- 页面现有低优先级队列改为严格空闲调度：有高优先级请求正在运行或等待时不启动低优先级任务，高优先级到来时取消在途低优先级请求。

### Push 与设置

- `weather-prefetch-options` 增加 `enabled: true`；旧配置缺少该字段时按开启迁移。
- 全局设置中的预加载开关与通知订阅解耦；关闭后立即取消 SW 任务并禁用 z、要素、气压层选项，开启并保存后启动最新时次任务。
- Push 在页面关闭时仍可将最新起报 SVG 写入 IndexedDB；关闭预加载后 Push 只通知，不下载。
- 旧版 `prefetch` 多时次消息保留兼容处理，但 SW 只选择其中最新的一个时次。

### 调试面板

- 在 `ControlRail.vue` 新增“SW 预加载”区块，显示支持状态、最新起报时次、当前状态、`IndexedDB 已就绪数 / 总数`、本轮新增下载数和失败数。
- 状态统一为：未启用、空闲、读取 Manifest、预加载中、前台请求暂停、已完成、存储受限、失败。
- SW 向全部页面发送节流后的 `prefetchStatus` 消息；页面挂载或 SW 重启后可主动请求持久化状态。
- 该面板只统计 SW 最新起报任务，不混入页面相邻预报时效预加载。

## 接口与状态契约

- 页面到 SW：新增单时次 `prefetchLatest`、`getPrefetchStatus`；保留 `cancelPrefetch`、`setPrefetchOptions` 和旧 `prefetch` 兼容入口。
- SW 到页面：统一发送 `prefetchStatus`，字段包括 `state`、`initTime`、`ready`、`total`、`downloaded`、`failed`、`reason`。
- 低优先级队列任务接收调度器提供的 `AbortSignal`，保证前台任务可以真正终止在途预加载连接。
- 不改变 Manifest、SVG 路径、瓦片坐标或绘图输出契约。

## 测试与验收

- 单元测试覆盖：旧设置迁移、禁用开关、只选择最新时次、单 SVG/瓦片 URL 收集、过滤与去重、失败记录跳过。
- IndexedDB 测试覆盖：SW 写入后页面命中且不访问网络、过期清理、v1 缓存升级、不同渲染倍率复用同一 SVG 源。
- 调度测试覆盖：重复启动不重复下载、新起报取消旧任务、前台请求立即暂停、空闲 2 秒恢复、高优先级任务与低优先级任务不并发。
- Push 测试覆盖：页面关闭时后台写入、关闭开关时只通知、过期 Push 不覆盖较新的目标。
- 手动验证控制栏计数与 DevTools IndexedDB 条目一致，并在网络限速下连续切换起报时次、预报时效和图层，确认无预加载连接竞争。
- 执行 `pnpm test` 和 `pnpm build`；制定本计划时的当前基线两者均通过。
- 保留工作区现有经纬网格相关未提交改动，合并 `ControlRail.vue` 时不覆盖用户修改。

## 已确认假设与默认值

- “最新起报时次”沿用前端现有 UTC 00/12 时次及生成延迟计算，不新增服务端查询接口。
- 新增总开关只控制 SW 最新起报预加载，不关闭页面现有的相邻预报时效预加载。
- 页面关闭后收到 Web Push 时继续执行后台缓存。
- 预加载开关对旧用户及首次使用者默认开启。
- 左侧调试面板只展示 SW 最新起报任务，不合并页面相邻时效预加载计数。
- 现有 z 层次、要素和气压层过滤语义保持不变；未选择要素或气压层表示不过滤。
